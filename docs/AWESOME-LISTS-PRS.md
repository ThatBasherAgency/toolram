## Strategy de aceptación

**Lo que ayuda a que acepten:**
- Tener 100+ GitHub stars (más probable después del PH launch)
- Tener docs visibles en el repo
- README claro con screenshots
- License explícita MIT

**Lo que mata el PR:**
- Sonar promocional ("the best!", "amazing!")
- No respetar el formato exacto de la lista
- Submitir un tool muy nuevo sin tracción

**Si rechazan:** preguntá qué falta, iterá, re-submitir en 2-3 meses.

## Timing recomendado

1. **Primero el Product Hunt launch** (genera ~100 stars en GitHub si va bien)
2. **2-3 semanas después**, abrir los 8 PRs (cuando ya tenés tracción visible)
3. Si te aceptan en 2-3, sumás backlinks DA 60+ permanentes
